## Detailed Description

TypePeek is a lightweight Chrome extension that helps designers and typography enthusiasts inspect, collect, and export font information from any text on the web.

### Inspect Instantly
Move your cursor over any text on a webpage and TypePeek shows you the font family, size, weight, line height, color, and letter spacing — no DevTools needed.

### Save & Research
Click the Save button on the tooltip to bookmark typography samples. Add notes, tags, and groups to build your own typography research library. All data is stored locally on your device.

### Export Study Cards
Export any saved record as a beautiful 800×500 PNG typography study card — perfect for design portfolios, case studies, or client presentations. Export all records as JSON for backup.

### Features
- Hover over any text to see font family, size, weight, line height, color, and letter spacing
- "Ag" preview glyph rendered in the detected font for quick visual confirmation
- Save typography samples with one click from the tooltip
- Organize saves with notes, tags, and custom groups
- Search and filter your collection in the popup dashboard
- Export individual records as PNG study cards
- Export all records as JSON for backup
- Floating control bar in the bottom-right corner: power toggle and quick access to collection
- Toggle detection on/off with Option + P (Mac) / Alt + P (Windows)
- Smart card positioning — never goes off-screen
- Works inside iframes
- Dark-themed UI with blur-glass styling
- Zero external dependencies — all data stays local

### Privacy
TypePeek stores all saved records locally using Chrome's storage API. No data is ever sent to external servers. No analytics, no tracking.
